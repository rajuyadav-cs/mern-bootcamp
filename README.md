# MERN Bootcamp 🚀

A hands-on repository documenting my journey of learning and building with the **MERN stack**, with a focus on backend development using Node.js, Express.js, and MongoDB.

## 🛠️ Tech Stack

- Node.js
- Express.js
- MongoDB
- Mongoose
- Next.js
- JavaScript (ES6+)
- REST APIs

## 📚 Learning Path

### Node.js

Core Node.js concepts, modules, filesystem, HTTP, npm, and asynchronous programming.

### Express.js

Routing, middleware, REST APIs, request/response handling, and backend architecture.

### MongoDB

Database operations, MongoDB queries, Mongoose, schemas, models, and data relationships.

## 🚀 Projects

The `projects/` directory contains practical applications built while applying the concepts learned throughout the bootcamp.

## 🎯 Goal

Learn by building and develop a strong understanding of modern full-stack web development.
